**TypeMaster** is a modern, feature-rich typing test application designed to help you improve your typing speed and accuracy. Test your skills with customizable settings, track your performance with real-time statistics, and get classified into professional-grade skill levels. Whether you are a beginner learning to type or an expert aiming to break records, TypeMaster provides a clean, distraction-free environment to practice and grow.

## Key Features

- **Flexible Test Modes**: Choose between Time-based tests (30s, 1m, 2m, 5m) or Word-based tests (25, 50, 100, 200 words) to suit your practice routine.
- **Adjustable Difficulty**: Select from Easy, Medium, or Hard text complexities to continually challenge yourself.
- **Real-Time Analytics**: Instantly track your Net WPM (Words Per Minute), Gross WPM, and Accuracy percentage as you type.
- **Visual Character Feedback**: Get immediate color-coded visual cues (green for correct, red for incorrect, blue for current) to easily spot mistakes.
- **Pause & Resume Functionality**: Need a break? Pause your active test at any time and resume exactly where you left off.
- **Performance Classification**: Automatically get graded into skill brackets (Novice, Beginner, Intermediate, Advanced, Expert) based on your final WPM.
- **Modern & Responsive UI**: A beautifully crafted, smooth, and distraction-free interface that works seamlessly across desktop, tablet, and mobile devices.

### Tech Stack

- **React**: Core library for building the highly interactive user interface.
- **TypeScript**: Ensures robust code architecture and type safety across the application.
- **Vite**: Next-generation frontend tooling for lightning-fast development and optimized production builds.
- **Tailwind CSS**: Utility-first CSS framework for crafting a modern, responsive, and custom design system.
- **Lucide React**: Provides beautiful, consistent, and customizable SVG icons used throughout the app.
- **ESLint**: Enforces code quality, consistency, and best practices.
- **PostCSS & Autoprefixer**: Used for processing modern CSS and ensuring cross-browser compatibility.
